# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Report security issues privately via a [GitHub Security Advisory](https://github.com/srkyn/relic/security/advisories/new).

Do not open a public issue for security vulnerabilities. Include a description of the issue, steps to reproduce, and relevant environment details.
